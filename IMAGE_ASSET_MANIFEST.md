# Archex — Image Asset Manifest & Content-to-Image Checklist

This document is the definitive checklist and inventory of all image assets across the Archex website. Use this reference to verify or rename your image files before placing them in the repository.

---

## Asset Guidelines

- **Root directory:** `public/resources/images/`
- **Preferred format:** WebP (`.webp`)
- **Naming rule:** Lowercase canonical slug with hyphens + `.webp`
- **Format Integrity:** If an original image is JPEG or PNG, convert the file format to genuine WebP before placing it in the codebase. Do not merely rename the file extension.
- **Missing File Behavior:** When an image is not present or fails to load, Archex renders the established classy geometric placeholder. Layout dimensions, typography, and theme styling remain stable.

```bash
npm run check:assets:strict
```
